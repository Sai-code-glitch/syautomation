Your data stays yours. Here's how.

Automations touch customer details, invoices and messages. We treat that data with the same care a bank would, and we write down exactly how.

Security practices

How we protect your business.

Client-owned accounts

Every tool is registered to your business. We're added as users and removed when work ends. No automations run on our personal accounts.

Least-privilege access

We ask only for the permissions an automation needs. Access is reviewed every quarter and on every project change.

Encrypted credentials

Passwords and API keys are shared through a secure form and stored in an encrypted vault, never sent by chat or email.

Two-factor everywhere

All team accounts use two-factor authentication. We help you turn it on for your own tools too.

Monitoring and logs

Automations report errors to us in real time, and every run is logged so we can trace what happened.

Data minimisation

We move only the data an automation needs and set retention limits so old personal data is deleted.

Responsible AI

AI that knows when to stop.

  • Assistants answer only from a knowledge base you approve.
  • Anything uncertain, sensitive or medical is handed to a person.
  • Customers are told they're talking to an AI assistant.
  • We use AI providers' business terms, which don't train models on your data.
  • You can read, export or delete every conversation.
